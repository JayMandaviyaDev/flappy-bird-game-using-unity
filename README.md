# Flappy Bird Game for Windows

This is a simple and fun Flappy Bird game created using the Unity game engine. Fly through the pipes and try to get the highest score!

## Features
- Classic Flappy Bird mechanics
- Engaging and colorful graphics
- Simple controls for an enjoyable experience

## Installation
1. Download the executable file from the link below.
2. Double-click the downloaded file to launch the game.
3. Start playing and have fun!

### [Download Flappy Bird for Windows](./Flappy%20Bird.exe)

## Controls
- **Spacebar**: Flap your wings

## About
This project was created as a fun exercise using Unity and C#. It's a great way to experience a classic game while exploring game development.

Enjoy the game!
